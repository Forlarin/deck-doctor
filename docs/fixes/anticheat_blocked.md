# This game's anti-cheat blocks the Steam Deck

Some multiplayer games use anti-cheat that refuses to run on Linux, which SteamOS is built on. No Proton version, setting or plugin can change this, and trying to get around it can get your account banned.

## What you can do
- **Cloud gaming:** Xbox Cloud Gaming (Game Pass Ultimate) or GeForce NOW run in a browser on the Deck.
- **Stream from a PC:** Moonlight or Steam Remote Play, if you have a gaming PC.
- Check [Are We Anti-Cheat Yet?](https://areweanticheatyet.com) to see if the game's status has changed.
