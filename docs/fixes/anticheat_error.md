# The anti-cheat failed to start

The game's anti-cheat (Easy Anti-Cheat, BattlEye or similar) reported an error.

## Fix
1. Check [Are We Anti-Cheat Yet?](https://areweanticheatyet.com) and ProtonDB. If the game is listed as "Denied" or "Broken", it can't run on the Deck.
2. If others report it working, make sure **Proton EasyAntiCheat Runtime** / **Proton BattlEye Runtime** are installed (search for them in your Steam library).
3. Try **Proton Experimental**, which usually has the newest anti-cheat support.
