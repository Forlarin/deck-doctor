# This game's controller layout has a button mixed up

Steam remembers a controller layout for each game. If one was changed at some point (on purpose or by accident), a main button can end up sending the wrong thing. For example, A sends RB, so nothing on the Deck sends A, and the game feels like it ignores you.

## Fix
1. While the game is running, press the **Steam** button and open **Controller Settings**. Or press **Open controller settings** in Deck Doctor.
2. Select **Edit Layout** (or the layout name at the top), then **Templates**.
3. Choose **Gamepad with Joystick Trackpad**, Steam's standard controller layout, then **Apply Configuration**.

The **Community** tab also has layouts other players made for the game, if you prefer one of those.
