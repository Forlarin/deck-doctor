# Some game files are damaged

The game's own log says it couldn't read part of its data. This usually happens when a big download was interrupted, the Deck went to sleep mid-download, or the SD card had a hiccup.

## Fix
1. Tap **Verify game files** in Deck Doctor. Or: open the game → ⚙ → **Properties** → **Installed Files** → **Verify integrity of game files**.
2. Wait for it to finish. Large games can take 10–20 minutes. Keep the Deck plugged in.
3. Steam re-downloads only the broken files. Launch the game again.

## If it keeps happening
- If the game is on the SD card, the card may be failing or slow. Try moving the game to internal storage (⚙ → Properties → Installed Files → Move install folder).
- Cheap or fake microSD cards are a common cause. A name-brand A2 card is worth it.
