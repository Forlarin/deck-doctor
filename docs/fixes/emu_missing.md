# The emulator isn't installed

The shortcut is set up for an emulator that isn't installed anymore. This usually happens after a SteamOS reset (which wipes emulators but not your SD card), or when EmuDeck stops shipping an emulator.

## Fix
1. Switch to Desktop Mode and open **EmuDeck**.
2. Go to **Manage Emulators** and install the emulator Deck Doctor named.
3. Back in Game Mode, launch the game again.

## Switch games
EmuDeck no longer includes a Switch emulator, after Nintendo had Yuzu and Ryujinx taken down. You'll need to install one yourself (Eden or Citron are the current community options), plus keys and firmware from your own Switch.
