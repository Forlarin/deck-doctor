# The game file is missing

The shortcut points to a game file that isn't there anymore.

## Fix
1. Check the SD card is inserted. Games on the SD card disappear when it's out.
2. If you moved or renamed the game file, put it back in the matching folder under **Emulation/roms**.
3. Re-run **Steam ROM Manager** (EmuDeck → Steam ROM Manager) so the shortcut points to the right file. Remove old shortcuts that point nowhere.
