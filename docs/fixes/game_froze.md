# The game didn't close normally

Steam saw the game start but never saw it end. That happens when a game freezes and the Deck is forced off by holding the power button, or when Steam itself crashes.

If Deck Doctor also showed a graphics freeze or running out of memory, follow that fix first.

## Fix, one at a time
1. Check ProtonDB for reports of the same freeze and the settings other players use.
2. Lower the graphics settings and cap the frame rate (... button → Performance).
3. Try a different Proton version.
4. Next time it freezes, open Deck Doctor before turning the Deck off and choose Force close the game. If the Quick Access menu still opens, that saves a forced shutdown.
