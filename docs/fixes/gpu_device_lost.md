# The graphics driver crashed

The game lost its connection to the GPU, which ends in a crash or freeze.

## Fix, one at a time
1. Lower the game's graphics settings, especially ray tracing and texture quality.
2. If the game offers DirectX 11 mode, use it instead of DirectX 12.
3. Try a different Proton version (Proton Experimental or GE-Proton).
4. Check ProtonDB for launch options other players use.
