# The graphics chip froze during the game

The Deck's graphics driver stopped responding and had to reset. On screen that looks like a frozen picture that ignores the buttons, sometimes followed by the game closing or the Deck restarting.

## Fix, one at a time
1. Lower the game's graphics settings, especially ray tracing, texture quality and upscaling.
2. Cap the frame rate: press the ... button, open Performance, and set the frame limit to 30 or 40.
3. Try a different Proton version (Proton Experimental or GE-Proton).
4. Check ProtonDB for the same freeze and the launch options other players use.
5. If it happens in many games, check for a SteamOS update in Settings → System.
