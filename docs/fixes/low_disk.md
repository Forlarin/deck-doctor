# Internal storage is almost full

Every Windows game keeps its Proton data and shader cache on the Deck's internal storage, even when the game itself is on the SD card. When internal storage fills up, games can fail to start or crash.

## Fix
1. Uninstall games you've finished.
2. Use the **Storage Cleaner** Decky plugin to clear old shader caches and leftover Proton data.
3. Settings → **Storage** shows what's using space.
