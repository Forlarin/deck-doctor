# The game needs .NET Framework

The game (or a tool it starts) needs Microsoft .NET Framework, which isn't included in this game's Proton setup.

## Fix
1. Try a **GE-Proton** version first. It often includes what's needed.
2. Otherwise, install .NET with Protontricks: in Desktop Mode, install **Protontricks** from Discover, then run `protontricks <appid> dotnet48` in Konsole. Replace `<appid>` with the game's number from Deck Doctor.
