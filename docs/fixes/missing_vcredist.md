# A Visual C++ runtime is missing

A Microsoft C++ runtime file the game needs is missing.

## Fix
1. **Verify game files** (⚙ → Properties → Installed Files → Verify). Steam runs the game's installers again, which usually puts the runtime back.
2. If that doesn't help, close the game and tap **Install Visual C++ runtimes** in Deck Doctor. It runs Protontricks for you in the background, with no Desktop Mode needed.
