# The game isn't fully installed or updated

Steam still has a download or update pending for this game, so it may refuse to start or start with missing files.

## Fix
1. Open Steam's **Downloads** page (press the Steam button → Downloads).
2. Let the game's update finish. If it's paused, tap **Resume**.
3. If it's stuck, restart the Deck and check Downloads again.
