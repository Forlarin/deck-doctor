# The Deck ran out of memory

The memory (RAM and swap) filled up, so Linux closed a program to recover. Before that point, games stutter and freeze.

## Fix, one at a time
1. Close other apps first. A web browser or Discord left open in Desktop Mode keeps using memory in Game Mode.
2. Lower the game's texture quality, which uses the most memory.
3. Restart the Deck before long sessions to clear anything left running.
4. Make the swap file bigger, which gives the Deck extra room when RAM is full. CryoUtilities (search for it on GitHub) does this from Desktop Mode.
