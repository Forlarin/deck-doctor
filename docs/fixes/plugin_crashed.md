# A plugin crashed when Decky started

The plugin's background part crashed during startup, so its features won't work. This often happens right after a SteamOS update, until the plugin's author releases a fix.

## Fix
1. Open the **Decky store** and update the plugin if an update is available.
2. Update Decky itself (Decky settings → General → check for updates).
3. If it still crashes, check the plugin's GitHub page for an open issue about it, or report it there with the error Deck Doctor shows.
