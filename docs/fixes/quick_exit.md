# The game closed right after starting

The game started and quit within a minute, and its logs don't name the cause. The most common fix is a different Proton version.

## Fix, one step at a time
1. Try the Proton versions Deck Doctor offers, starting with the first. Launch the game after each change.
2. Check **ProtonDB** for the game: other players list which Proton version works and any extra steps.
3. Verify the game files (⚙ → Properties → Installed Files → Verify).
4. Use **Undo Deck Doctor's Proton change** to go back if nothing helped.

## Careful
- Games with **Denuvo** can lock you out for 24 hours if you switch Proton versions many times in a row. Space out your attempts.
- Change one thing at a time, so you know what fixed it.

## For non-Steam shortcuts (emulators)
The problem is usually inside the emulator: a missing BIOS, keys or firmware file, or a game file it can't read. Open the emulator directly from Desktop Mode to see its error.
