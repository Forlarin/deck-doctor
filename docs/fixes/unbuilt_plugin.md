# A plugin folder is source code, not a plugin

A plugin folder has no built frontend (`dist/index.js`). This happens when a plugin is downloaded with GitHub's green **Code → Download ZIP** button. That ZIP is the source code, not the plugin.

## Fix
1. Tap **Move to backup** to get it out of the way.
2. Install the plugin properly: from the **Decky store**, or from the project's **Releases** page (the ZIP attached to a release, not "Source code").
